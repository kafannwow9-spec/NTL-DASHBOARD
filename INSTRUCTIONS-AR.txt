دمج واجهات NTL Dashboard
========================

- الصفحة الرئيسية وتسجيل الدخول واختيار السيرفر: من المشروع الأول.
- الضغط على "تسطيب وإدارة" يفتح manage.html المبني بواجهة الإدارة من المشروع الثاني.
- يتم تمرير guildId إلى واجهة الإدارة حتى يتم اختيار السيرفر نفسه.
- لا توجد قائمة سيرفرات تجريبية في واجهة الإدارة؛ تعرض فقط نتيجة /api/guilds الحقيقية.
- لا يوجد ملف db.json في هذه النسخة.
- المنفذ لم يتم تغييره؛ إعداد المنفذ الأصلي في server.js كما هو.

التشغيل:
1) فك الضغط داخل مجلد المشروع.
2) npm install
3) npm run build
4) npm start

الأسرار:
لا حاجة إلى Environment Variables. ضع القيم الجديدة داخل config.json فقط.
تم تفريغ CLIENT_SECRET وBOT_TOKEN وBOT_TOKEN_2 وBOT_SECRET عمدًا لأن بيانات الاعتماد
التي كانت داخل الملف المرفوع ظهرت في سياق المحادثة ويجب تدويرها/إلغاؤها قبل الاستخدام.
أدخل القيم الجديدة في config.json ولا تعِد استخدام الأسرار القديمة.
تأكد من أن Discord OAuth Redirect URI يطابق القيمة الموجودة في config.json.
